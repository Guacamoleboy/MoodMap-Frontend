# What is the purpose of the package.json file and what can you do with it?

### Mit Svar inden hjælp

Jeg vil næsten sammenligne package.json med pom.xml i Java til vores REST API. Den forklarer hvad applikationen indeholder af dependencies, og så kan npm install dem korrekt såfremt det er initial installation.
Herudover kan man lave versionsstyring og setups til fx development og production med hhv "dependencies": og "devDependencies": og meget mere.
