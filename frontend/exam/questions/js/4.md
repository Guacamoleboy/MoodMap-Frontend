# Show and explain how to use the fetch function in JavaScript.

### Mit Svar inden hjælp

Fetch - som navnet hentyder til - henter data fra noget.. I vores tilfælde er det en REST API som vi fetcher data fra.
Der er mange måder at sætte Fetch op. Der er hjælpe dependencies som fx SWR som har cache og fjerner en del af boilerplate samt errorhandling boilerplate.
Men som udgangspunkt er fetch bare en betegnelse for at fetche noget. Data primært.
