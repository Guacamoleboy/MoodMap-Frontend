# What is the main concept of an React component? Show and explain in your own code.

### Mit Svar inden hjælp

Hovedkonceptet bag en React component, er UI som er genanvendeligt. Jeg brugte det i tidligere projekter i html som modules som ren .js filer.
Ved at dele UI ud i egne folders og components får man scope hvor man kan edit og vedligeholde nemmere end normalt.
Ved at bruge .hooks.js og .module.css får vi et "lokalt" scope forstået på den måde, at componentens ting er tilhørende den og KUN den.
