# Show and explain the useEffect hook (eg. callback, dependency array etc.)

### Mit Svar inden hjælp

Callback er selve funktionen eller dét som useEffect skal lave.
Dependency array holder styr på hvornår side effect bliver kørt. Tom Array kører 1 gang ved mount. Ingen array kører hver render. Dependency så kører den når dependency ændrer sig. 

Cleanup bruges til når den skal re-render altså til at reset et eller andet fx eller unmounter.
