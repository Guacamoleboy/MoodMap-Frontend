# Show and describe the purpose of props including children.

### Mit Svar inden hjælp

Lidt som parameter i Java, så sender props data videre. Det kunne fx være..

```JavaScript
<Dropdown link="/wontadd" />
```

```JavaScript
function Dropdown({ link }) {

}
```

Vi sender altså data videre ligesom vi gjorde i Java.

Children derimod er ikke en fast værdi, men siger bare, at vi har noget indhold. Dette indhold skal så sendes videre. Det vil sige children (indholdet) bliver modtaget herefter.
Det kunne fx være vi sender en h1 afsted eller tilsvarende. Denne er ikke tekst som en prop, men reel kode.
