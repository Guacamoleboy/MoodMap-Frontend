# What is JSX? Provide an example. How would you write the same functionality if you only used Javascript, HTML and DOM manipulation?

### Mit Svar inden hjælp

.jsx filer gør bare, at vi kan formulere html heri som så bliver compiled til JavaScript når den compiles.

I normal JavaScript ville man lave divs eller h1 måske, og så ville man target IDs, div navne eller tilsvarende via DOM manipulation. Ved at lave .jsx filer og .hooks.js filer mm kan vi sikre os,
at alt spiller sammen på et bedre og mere effektivt niveau.
